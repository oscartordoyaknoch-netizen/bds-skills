# Workspace BDS

## Que es

El `BDS Workspace` es la instalacion practica del `Business Design System` para un negotium especifico.

No redefine la doctrina. La vuelve operativa.

## Diferencias clave

- `Documento Madre`: explica que es el sistema.
- - `Project Builders`: explican como se estructura cada dimension.
  - - `Workspace BDS`: explica como instalar todo eso para gobernar un negocio real.
    - - `Caso BDS`: aplica la lectura a una empresa o situacion concreta.

                              - ## Regla operativa
                             
                              - Cuando el usuario pida instalar, organizar o pensar un `BDS Workspace`, la skill debe:
                             
                              - 1. identificar el negotium
                                2. 2. definir objetivo de instalacion
                                   3. 3. proponer la estructura madre
                                      4. 4. decidir que dimensiones son prioritarias
                                         5. 5. definir artefactos iniciales
                                            6. 6. conectar decisiones, evidencia y learning
                                              
                                               7. ## Minimo util del workspace
                                              
                                               8. Aunque no exista aun una implementacion completa, un `BDS Workspace` util debe permitir:
                                              
                                               9. - entender el negotium
                                                  - - ver su estado actual
                                                    - - clasificar informacion por dimensiones
                                                      - - recibir documentos entrantes
                                                        - - producir diagnosticos
                                                          - - registrar decisiones
                                                            - - registrar learning
