# Output Patterns

## Regla base

No producir por inercia todos los artefactos posibles. Elegir el minimo conjunto que deja al usuario con algo util, accionable y trazable.

## Si el usuario pide explicacion doctrinal

Producir:

- explicacion clara
- - distincion entre capas o artefactos BDS
  - - relaciones clave
   
    - ## Si el usuario pide clasificacion
   
    - Producir:
   
    - - dimension principal
      - - dimensiones secundarias si existen
        - - explicacion breve de por que
          - - riesgos de clasificar mal
           
            - ## Si el usuario pide instalar o pensar un workspace
           
            - Producir:
           
            - - arquitectura del workspace
              - - prioridades de instalacion
                - - artefactos iniciales
                  - - reglas de uso
                   
                    - ## Si el usuario pide un caso BDS
                   
                    - Producir:
                   
                    - - estructura de caso
                      - - fuentes
                        - - lectura por dimensiones
                          - - problemas, riesgos, oportunidades
                            - - primeras decisiones o siguientes pasos
                             
                              - ## Si el usuario pide diagnostico
                             
                              - Producir:
                             
                              - - lectura por dimensiones o capas
                                - - bloqueos
                                  - - riesgos
                                    - - oportunidades
                                      - - prioridades
                                       
                                        - ## Si el usuario pide tablero o mapa
                                       
                                        - Producir:
                                       
                                        - - propuesta de nodos o modulos
                                          - - que debe verse
                                            - - que debe medirse
                                              - - que decisiones debe habilitar
                                               
                                                - ## Si el usuario pide trabajar con documentos o memoria
                                               
                                                - Producir:
                                               
                                                - - routing recomendado
                                                  - - evidencia necesaria
                                                    - - nota o estructura objetivo
                                                      - - decision sobre si hace falta derivar a una skill operativa
