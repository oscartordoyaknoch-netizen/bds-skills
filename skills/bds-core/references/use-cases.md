# Use Cases

## 1. Doctrinal explanation

Trigger examples:

- `explicame que es el BDS`
- - `cual es la diferencia entre documento madre y workspace`
 
  - Expected behavior:
 
  - - explain clearly
    - - distinguish doctrine, component, workspace, and case
      - - avoid producing unnecessary artifacts
       
        - ## 2. Business reading
       
        - Trigger examples:
       
        - - `usa BDS con este negocio`
          - - `lee esta empresa con logica BDS`
           
            - Expected behavior:
           
            - - identify negotium
              - - detect likely dimensions involved
                - - propose a minimum useful artifact set
                  - - surface risks, opportunities, and missing information
                   
                    - ## 3. Caso BDS creation
                   
                    - Trigger examples:
                   
                    - - `convierte esto en caso BDS`
                      - - `quiero un caso BDS para esta empresa`
                       
                        - Expected behavior:
                       
                        - - define context and objective
                          - - list sources
                            - - classify signal by dimensions
                              - - propose diagnosis, decisions, and learning structure
                               
                                - ## 4. Workspace installation
                               
                                - Trigger examples:
                               
                                - - `instala conceptualmente el workspace BDS`
                                  - - `como seria el BDS Workspace para este negotium`
                                   
                                    - Expected behavior:
                                   
                                    - - explain the workspace architecture
                                      - - prioritize first folders or modules
                                        - - define startup artifacts
                                          - - connect doctrine to practical operation
                                           
                                            - ## 5. Dimension routing
                                           
                                            - Trigger examples:
                                           
                                            - - `esto es ventas o control`
                                              - - `clasifica este problema en BDS`
                                               
                                                - Expected behavior:
                                               
                                                - - choose main dimension
                                                  - - mention secondary dimensions if relevant
                                                    - - explain the routing briefly
                                                     
                                                      - ## 6. Operational derivation
                                                     
                                                      - Trigger examples:
                                                     
                                                      - - `procesa estos documentos de una empresa con BDS`
                                                        - - `haz una salida repetible y auditada`
                                                         
                                                          - Expected behavior:
                                                         
                                                          - - use `bds-core` for criterion and artifact definition
                                                            - - derive to `bds-operator` when scripted ingestion, repeatable generation, or audit is the right path
